# แบบขอมีเวชระเบียนผู้ป่วยนอก (ออนไลน์)

แบบฟอร์ม **FM-NMD-OPD-01-R02-01-67** สำหรับสถานพยาบาลปฐมภูมิ ทร. เป็นหน้าเว็บล้วน (GitHub Pages) ไม่มีเซิร์ฟเวอร์ และไม่เก็บข้อมูลผู้ป่วยไว้ที่ใด

- ถ่ายรูปบัตรประชาชน → ดึงเลขบัตร ชื่อ-สกุล เพศ วันเกิด ศาสนา ที่อยู่ ให้อัตโนมัติ (อ่านบนเครื่องผู้ใช้)
- เซ็นชื่อบนหน้าจอ
- สร้างแบบฟอร์มหน้าตาตรงต้นฉบับพร้อมลายเซ็น แล้ว **บันทึก PDF / ส่งไฟล์ (LINE, อีเมล) / พิมพ์**

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแบบฟอร์ม |
| `qr.html` | โปสเตอร์ QR code สำหรับพิมพ์ติดจุดบริการ |
| `config.js` | ตั้งค่าชื่อหน่วยที่พิมพ์บนแบบฟอร์ม |

## เปิดใช้งาน
**Settings > Pages > Build and deployment** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save

ภายใน 1–2 นาที:
- แบบฟอร์ม: `https://<บัญชี>.github.io/<repo>/`
- โปสเตอร์ QR: `https://<บัญชี>.github.io/<repo>/qr.html` → กด "พิมพ์โปสเตอร์"

## การแก้ไข
แก้ไฟล์บน GitHub ได้เลย ลิงก์และ QR code เดิมใช้ต่อได้

## ข้อมูลส่วนบุคคล
ข้อมูลที่กรอกและภาพบัตรอยู่บนเครื่องผู้ใช้เท่านั้น ไม่ถูกส่งไปที่ใด ไฟล์ PDF ที่ได้ ผู้ป่วยนำมาแสดง/ส่งให้เจ้าหน้าที่เอง
