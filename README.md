# แบบขอมีเวชระเบียนผู้ป่วยนอก (ออนไลน์)

แบบฟอร์ม **FM-NMD-OPD-01-R02-01-67** สำหรับสถานพยาบาลปฐมภูมิ ทร. ให้ผู้ป่วยกรอกเองผ่านมือถือ

- ถ่ายรูปบัตรประชาชน → ดึงเลขบัตร ชื่อ-สกุล เพศ วันเกิด ศาสนา ที่อยู่ ให้อัตโนมัติ (อ่านบนเครื่องผู้ใช้ ไม่ส่งภาพบัตรออกไป)
- เซ็นชื่อบนหน้าจอ
- สร้างแบบฟอร์มหน้าตาตรงต้นฉบับ พร้อมลายเซ็น
- ส่งคำขอ → บันทึกลง Google Sheet และเก็บ PDF ใน Google Drive ของหน่วยงาน → ได้เลขที่คำขอ

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแบบฟอร์ม (GitHub Pages) |
| `qr.html` | โปสเตอร์ QR code สำหรับพิมพ์ติดจุดบริการ |
| `config.js` | **ตั้งค่า** URL ของ Apps Script และชื่อหน่วย |
| `apps-script/Code.gs` | ฝั่งรับข้อมูล วางใน Google Apps Script |

## ติดตั้ง

### 1) ฝั่งรับข้อมูล (Google Apps Script)
1. สร้าง Google Sheet ใหม่ด้วยบัญชีหน่วยงาน → เมนู **ส่วนขยาย > Apps Script**
2. วางเนื้อหา `apps-script/Code.gs` แทนโค้ดเดิม แล้วบันทึก
3. เลือกฟังก์ชัน `setup` → **เรียกใช้** → อนุญาตสิทธิ์
4. **การทำให้ใช้งานได้ > รายการใหม่ > เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
5. คัดลอก URL ที่ลงท้ายด้วย `/exec`

### 2) ตั้งค่าหน้าเว็บ
แก้ไฟล์ `config.js` บน GitHub:
```js
GAS_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
UNIT_NAME: "ชื่อหน่วย"
```

### 3) เปิด GitHub Pages
**Settings > Pages > Build and deployment** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save

ภายใน 1–2 นาที:
- แบบฟอร์ม: `https://<บัญชี>.github.io/<repo>/`
- โปสเตอร์ QR: `https://<บัญชี>.github.io/<repo>/qr.html`

## การแก้ไขภายหลัง
- หน้าเว็บ: แก้ไฟล์บน GitHub ได้เลย URL และ QR เดิมใช้ต่อได้
- Apps Script: แก้แล้ว **จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่** (อย่าสร้าง deployment ใหม่ เพราะ URL จะเปลี่ยน)

## ข้อมูลส่วนบุคคล (PDPA)
- repo นี้ไม่มีข้อมูลผู้ป่วย ข้อมูลทั้งหมดอยู่ใน Google Sheet / Drive ของหน่วยงาน
- แชร์ชีตและโฟลเดอร์ PDF เฉพาะเจ้าหน้าที่ที่เกี่ยวข้อง ห้ามตั้ง "ทุกคนที่มีลิงก์"
- ฝั่ง Apps Script ตรวจเลขบัตร ลายเซ็น และไฟล์ PDF ก่อนบันทึก และจำกัด 30 คำขอ/นาที
